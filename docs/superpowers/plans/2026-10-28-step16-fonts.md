# Step 16: choose the font on iPhone and iPad — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (chosen) to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Settings ▸ Appearance gains a **Font** picker (13 fonts, each row drawn in its own font) that restyles all app text and figures on iPhone and iPad; Mac unchanged.

**Architecture:**
- **BudgetCore owns the catalogue** (`Sources/BudgetCore/Themes/FontCatalog.swift`): ids, display names, kind (system / bundled), PostScript names per weight, `hasTabularDigits`. Pure, tested.
- **MangoUI owns the drawing** (`Sources/MangoUI/DesignSystem/PhoneTypeface.swift`): an environment value `\.phoneTypeface`, a `View.mangoFont(_:weight:)` modifier that replaces the app's ~370 semantic `.font(.headline)` calls, the registration of bundled files (`BundledFonts.register()`), and the tabular-figure fallback in `MoneyText` / `figureText`.
- **Phone owns the files and the setting:** `Phone/Fonts/` (10 families + OFL.txt each), `@AppStorage("phone.font")` next to `phone.theme` in `MangoPhoneApp`. Per device, not synced, not in CloudKit.

**Tech Stack:** Swift 6, SwiftUI, CoreText (`CTFontManagerRegisterFontsForURLs`), XCTest, XcodeGen.

**Spec:** `docs/superpowers/specs/2026-10-28-step16-fonts-design.md` (binding; *(my call)* items accepted, extended by the calls marked *(plan call)* below).

## Global Constraints

- **13 fonts, default SF Pro:** SF Pro (system), SF Pro Rounded (system), New York (system serif), Inter, IBM Plex Sans, Source Sans 3, Public Sans, DM Sans, Manrope, Atkinson Hyperlegible, Lexend, Source Serif 4, IBM Plex Mono. The 10 non-system fonts are bundled, regular / medium / semibold / bold weights only, each family's OFL licence included.
- **Applies to all app text** through the shared design system, scaling with Dynamic Type via `Font.custom(_:size:relativeTo:)`.
- **Money keeps tabular figures in every font**; a font without tabular digits uses the system font's tabular digits for figures (`hasTabularDigits == false`).
- **Widgets keep the system font. The Mac is unchanged** (no `App/` file changes; `MangoUI` must still compile for macOS: guard CoreText/UIKit code accordingly).
- **No figure wraps or truncates in any font** at the largest non-accessibility size and at accessibility sizes: the snapshot harness renders every route in SF Pro, Lexend (wide) and IBM Plex Mono (widest) and the wrap report has no violations. Names truncate in the middle.
- **Logic in BudgetCore/MangoUI with tests**; setting is per-device `UserDefaults`, never synced, no new CloudKit field.
- **Nothing personal committed.** Tests never touch the real DB, Keychain, iCloud or `/Applications`; no subagent runs `scripts/install-app.sh`.
- **Build the Phone target with `xcodebuild`** for any task touching `Phone/`, `Sources/MangoUI/`, `project.yml`.
- **Commands** (`S16=/tmp/mango-16-build`, outside `~/Documents` because of iCloud CodeSign issues):
  - targeted: `swift test --scratch-path $S16 --filter '<Tests>'`
  - full suite, once at the end of each task: `swift test --scratch-path $S16 --parallel`
  - phone/iPad build: `scripts/build-phone.sh`
  - Mac build (task 2 and 3, proves the Mac still compiles): `xcodegen generate && xcodebuild -project Mango.xcodeproj -scheme Mango -configuration Debug -derivedDataPath $S16/dd CODE_SIGNING_ALLOWED=NO build`
  - snapshots: `scripts/render-phone-snapshots.sh $S16/snaps [--device ipad] --only <routes>`
  - **at most 2 building agents at once.**
- **Model tags:** **[opus]** = logic plus a spec+code review. **[sonnet]** = plumbing/UI: quick review.
- **Dropping tasks: drop from the end.** Task 3 (picker, licences, snapshots) is the UI half; Tasks 1-2 alone ship nothing visible, so the step is dropped whole, last in the unattended run.

## Calls extending the spec

- *(plan call)* Fonts are registered at launch with `CTFontManagerRegisterFontsForURLs` (scope `.process`) from `BundledFonts.register()`, not `UIAppFonts`: no 30-entry plist list, and the snapshot build and unit tests share one code path.
- *(plan call)* Variable TTFs are accepted where Google ships only those (Inter, Source Sans 3, Public Sans, DM Sans, Manrope, Lexend, Source Serif 4); weight comes from `Font.weight`. Static files for IBM Plex Sans/Mono and Atkinson Hyperlegible (regular + bold only: Google ships no medium/semibold; medium and semibold map to bold) *(plan call)*.
- *(plan call)* The `.font(.style)` migration is a mechanical rewrite to `.mangoFont(.style)`; `.font(.system(size:…))`, `Font.largeTitle` inside `Text` concatenation and `UIFont` uses in `PadRoutes.swift` (PDF page drawing) stay as they are.
- *(plan call)* Licences: bundled as `Phone/Fonts/<family>/OFL.txt` and listed in a "Font licences" screen under Settings ▸ About (there is no Acknowledgements screen yet; this is its first entry).

## Review Focus

1. **Stored font id that no longer exists (older/newer build, hand-edited defaults).** Expect SF Pro, never a crash or blank text. Task 1: `testUnknownIdFallsBackToSFPro`.
2. **A bundled file missing or not registered (bad copy, renamed file).** Expect the catalogue test to fail loudly in CI, and at run time the font silently falls back to SF Pro, never missing glyphs. Task 1: `testEveryBundledFontFileExistsAndMatchesItsPostScriptName`; Task 2: `testFallbackWhenFontNotRegistered`.
3. **Money in a font with proportional digits.** Expect the figure drawn in the system font's tabular digits, columns aligned. Task 2: `testFiguresUseSystemFontWhenFontLacksTabularDigits`.
4. **Largest sizes in the widest fonts (Lexend, IBM Plex Mono at accessibility 5).** Expect no wrap report violations. Task 3: snapshot step.
5. **Weight requested that a family lacks (Atkinson medium/semibold).** Expect the nearest bundled weight, never the system font mid-sentence. Task 2: `testWeightMapsToNearestBundledWeight`.
